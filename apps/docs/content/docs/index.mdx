# Welcome to Linea

Linea is a **workflow automation platform** for building and running AI agent pipelines. Connect nodes into workflows, deploy them, and trigger them on a schedule, via webhook, or from your own code.

## What you can build

- Multi-step AI pipelines with memory across executions
- Human-in-the-loop approval flows
- Scheduled automations and webhook-triggered workflows
- Workflows that call Slack, GitHub, Notion, Gmail, or any HTTP endpoint
- Agent workflows that query your own document knowledge bases
