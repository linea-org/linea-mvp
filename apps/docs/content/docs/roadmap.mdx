# Roadmap

## Shipped

| Feature | Description |
|---|---|
| Workspace & Space hierarchy | Two-level org model: Workspace → Space → Workflow |
| Visual workflow builder | Drag-and-drop canvas with 20+ node types |
| Execution engine | LangGraph-backed runtime with BullMQ queue |
| PostgreSQL checkpointer | Durable execution state via `@langchain/langgraph-checkpoint-postgres` |
| Agent nodes | Multi-provider LLM support (Anthropic, OpenAI, Groq, Google) |
| Structured output | Force any agent node to return typed JSON via schema injection |
| Loop node | Iterate over array variables with optional item transform |
| Sub-workflow node | Invoke another workflow inline and capture its output |
| Built-in integrations | Slack, GitHub, Notion, Gmail nodes with secret-based auth |
| TypeScript SDK | `@linea/sdk` — trigger, poll, and stream executions |
| Memory system | Thread- and workflow-scoped fact storage with pgvector hybrid search |
| Knowledge bases | Workspace document stores with vector similarity search |
| MCP tools | Attach Model Context Protocol servers to agent nodes |
| Schedules & Webhooks | Cron triggers and inbound HTTP event hooks |
| API keys | `lnk_` workspace keys with SHA-256 hashing |
| RBAC | Role-based access: owner / admin / editor / viewer per workspace |
| SSE streaming | Real-time node update events for running executions |
| Swagger UI | Interactive API docs at `/docs` |
