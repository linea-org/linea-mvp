# Nodes

Every workflow is a directed graph of **nodes** connected by **edges**. Each node type serves a specific purpose — running LLM inference, branching on a condition, sending a Slack message, and so on.

For the full configuration reference for each node type, see the [Node Reference](/docs/nodes) section.

## Variable Substitution

All string fields in node configuration support `{{variableName}}` substitution:

| Syntax | Resolves to |
|---|---|
| `{{input.field}}` | Field from the trigger input payload |
| `{{nodeName}}` | Output of a previous node (by name or ID) |
| `{{lastOutput}}` | Output of the most recently completed node |
| `{{nodeResults.nodeId.output}}` | Deep-access a specific node result |
| `{{variables.myVar}}` | Any variable in the LangGraph state |

Substitution is applied to all string fields across all node types, including object values (e.g. individual header values in the HTTP node).

<Callout type="info">
  References like `{{input.data.items.0.name}}` with dot-path traversal work as expected. Undefined references resolve to an empty string.
</Callout>

## Node Quick Reference

| Node | Category | Purpose |
|---|---|---|
| [start](/docs/nodes/start) | Core | Entry point — initializes state from trigger input |
| [end](/docs/nodes/end) | Core | Terminal — marks execution complete |
| [agent](/docs/nodes/agent) | AI | LLM with tool use, structured output, long-term memory |
| [memory](/docs/nodes/memory) | AI | Read/clear in-workflow key-value memory |
| [if-else](/docs/nodes/if-else) | Logic | Branch on a boolean Jexl expression |
| [router](/docs/nodes/router) | Logic | Multi-branch routing via prioritized conditions |
| [http](/docs/nodes/http) | Tools | HTTP requests to external APIs |
| [mcp](/docs/nodes/mcp) | Tools | Model Context Protocol tool invocation |
| [transform](/docs/nodes/transform) | Data | Reshape variables with a Jexl expression |
| [extract](/docs/nodes/extract) | Data | Web scraping via Firecrawl or native fetch |
| [retriever](/docs/nodes/retriever) | Data | Knowledge base search |
| [code](/docs/nodes/code) | Data | Sandboxed JS execution (disabled — see page) |
| [loop](/docs/nodes/loop) | Flow | Iterate over an array |
| [subworkflow](/docs/nodes/subworkflow) | Flow | Call another workflow synchronously |
| [guardrails](/docs/nodes/guardrails) | Safety | PII / jailbreak / harmful content detection |
| [approval-gate](/docs/nodes/approval-gate) | Safety | Human-in-the-loop checkpoint |
| [slack](/docs/nodes/slack) | Integration | Send Slack messages or DMs |
| [github](/docs/nodes/github) | Integration | GitHub issues and pull requests |
| [notion](/docs/nodes/notion) | Integration | Notion pages and database queries |
| [gmail](/docs/nodes/gmail) | Integration | Send and read Gmail messages |
| [note](/docs/nodes/note) | Misc | Canvas annotation (no runtime effect) |
